## Hi, I’m swallowjp.

I maintain open-source tooling for MQL5/MT5 Expert Advisor safety, risk checks, and backtest audit workflows.

My current focus is building practical components and documentation for:

* EA risk guards
* lot-size safety checks
* account-currency assumptions
* broker server time vs local time handling
* JPY/USD backtest conversion
* backtest-to-live discrepancy review
* operational checklists for first-time EA users

This work is not financial advice and does not provide profitable trading signals.
The goal is to make automated-trading systems safer, more auditable, and easier to review.
